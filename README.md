# Tic-tac-toe with AI

The implementation of the game "Multi tic-tac-toe" with AI in C++.

## Build and launch

1. Clone the repository
2. Assemble the project: `make`
3. Start the game: `bin/tic_tac_toe`
4. To run the tests: `make run_tests`
5. To generate documentation: `make doc`

## Management

- Enter coordinates in classic tic-tac-toe in row-column format (for example, "1 2")
- Enter coordinates in 3D tic-tac-toe in cube-row-column format (for example, "1 2 3")
- The AI automatically makes a move after your

## Features

- Classic tic-tac-toe and 3D tic-tac-toe
- Playing with a human AI in both game variants
- Man-to-man game in both game variants
- Three levels of AI difficulty
- Exit using the word "exit"
- Full test coverage
- Doxygen documentation
