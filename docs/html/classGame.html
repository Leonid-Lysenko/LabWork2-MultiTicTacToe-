◆ start()

void Game::start ( )

Starts the game loop.

Depending on the mode, runs the game loop for classic or 3D tic-tac-toe. Handles player turns until the game ends or exit is requested. Displays the final game state.

Exceptions
std::exceptionPropagates exceptions not related to player exit.
