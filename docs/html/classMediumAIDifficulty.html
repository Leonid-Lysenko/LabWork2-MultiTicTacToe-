Calculates the best move for the AI.

Calculates the best move for the AI using a medium difficulty strategy.

Parameters
boardThe current game board.
aiMarkerThe AI's marker.
Returns
The position of the best move.

The strategy is:

  1. Win immediately if possible.
  2. Block opponent's winning move if imminent.
  3. Take center if available.
  4. Otherwise, make a random move.
Parameters
boardThe current game board.
aiMarkerThe AI player's marker.
Returns
The chosen Position for the move.

Implements AIDifficulty.
