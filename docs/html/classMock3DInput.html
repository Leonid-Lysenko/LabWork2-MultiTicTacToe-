Detailed Description

Mock input handler for simulating 3D game inputs in tests.

Mock input handler to simulate 3D game inputs for human players.

Provides a sequence of predefined inputs for 3D positions and supports simulating an exit request.

Provides a predefined sequence of 3D moves for testing purposes.
